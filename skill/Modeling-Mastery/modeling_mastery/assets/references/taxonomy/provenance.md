# Provenance 规则

- `PAPER_EXPLICIT`：论文正文、公式、图表或代码明确给出。
- `PAPER_DERIVED`：可以由论文的相邻公式或明示步骤直接整理得到，但不是原句。
- `AI_INFERRED`：为形成完整结构或代码而推测，必须人工检查。
- `EXTERNAL_REFERENCE`：来自教材、参考仓库或通用知识，不得声称属于当前论文。
- `HEURISTIC`：由关键词、正则或名称匹配得到，只用于离线骨架。

参数、停止条件、复杂度和数据预处理最容易被模型擅自补全。论文没有给出时，保留 `null` 或 `unknown`，不要写“通常取 100”然后伪装成论文设置。
