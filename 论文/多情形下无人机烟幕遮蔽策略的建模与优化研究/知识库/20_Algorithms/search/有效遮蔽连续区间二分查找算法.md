# 有效遮蔽连续区间二分查找算法

> [!abstract] 用途
> 在问题一中定位单一连续有效遮蔽区间的开始和结束时刻。

## 基本属性

- 分类：`search`
- 来源等级：`PAPER_EXPLICIT`
- 置信度：99%
- 输入：遮蔽判定函数C(t)=Bool(t)、起爆时间t_b、20 s有效窗口、精度ε
- 输出：t_in、t_out、T=t_out-t_in

## 伪代码

```text
1. 设置初始测试点集S0={t_b,t_b+10,t_b+20}和网格尺寸δ0=10
2. 逐步缩小时间网格，寻找满足C(t)=1的内部时刻t*
3. 在[t_b,t*]上二分：若C(mid)=1则向左收缩有效边界，否则向右移动
4. 在[t*,t_b+20]上二分：根据C(mid)更新结束边界
5. 当搜索区间宽度小于ε时停止
6. 返回t_in、t_out及其差值
```

## 初始化与停止条件

- 初始化：以起爆时刻和起爆后10 s、20 s作为初始测试点。
- 停止条件：二分区间宽度小于ε；内部有效点搜索达到给定时间精度

## 参数

| 参数 | 值 | 范围 | 说明 | 来源 |
|---|---|---|---|---|
| `初始点集` | {t_b,t_b+10,t_b+20} | - | 寻找内部有效时刻的初始时间点。 | PAPER_EXPLICIT |
| `初始网格尺寸δ0` | 10 | - | 初始时间搜索步长。 | PAPER_EXPLICIT |
| `时间精度ε` | 10^-5 | - | 二分查找终止精度。 | PAPER_EXPLICIT |
| `有效窗口` | 20 | - | 起爆后搜索区间的最大长度。 | PAPER_EXPLICIT |

## 复杂度

- 时间：`每个边界需要O(log((b-a)/ε))次Bool评价，单次评价还包含O(n)个几何判定；为PAPER_DERIVED。`
- 空间：`除遮蔽评价器外为O(1)；为PAPER_DERIVED。`
- 说明：无

## 随机性与复现

- 使用随机性：否
- 必须固定 seed：否
- 说明：无

## 实现要点

- 依赖问题一有效区间单一且连续的结论
- 搜索范围应限制在云团起爆后的20 s内

## 常见失败模式

- 若有效集合包含多个区间，单次二分可能遗漏其他区间
- 若初始扫描未发现内部有效点，则无法建立二分区间
- 边界附近的离散误判会影响终止结果
