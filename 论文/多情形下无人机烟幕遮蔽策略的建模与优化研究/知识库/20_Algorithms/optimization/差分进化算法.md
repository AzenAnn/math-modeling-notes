# 差分进化算法

> [!abstract] 用途
> 求解问题三的高维、非线性、无梯度投弹优化，并用于问题四的独立复算。

## 基本属性

- 分类：`optimization`
- 来源等级：`PAPER_EXPLICIT`
- 置信度：99%
- 输入：有界决策向量、有效遮蔽时长适应度函数、约束违反度
- 输出：历史最优个体、最大有效遮蔽时长

## 伪代码

```text
1. 在可行域内随机初始化种群
2. 通过仿真计算适应度并用惩罚函数整合约束违反度
3. 为每个目标个体随机选择三个不同个体并生成变异向量
4. 执行二项式交叉生成试验向量
5. 若试验向量更优则替换目标个体
6. 迭代至最大代数并输出历史最优个体
```

## 初始化与停止条件

- 初始化：在各决策变量的可行范围内随机初始化100个个体。
- 停止条件：达到500代

## 参数

| 参数 | 值 | 范围 | 说明 | 来源 |
|---|---|---|---|---|
| `种群规模N` | 100 | - | 差分进化种群规模。 | PAPER_EXPLICIT |
| `最大迭代次数G` | 500 | - | 最大进化代数。 | PAPER_EXPLICIT |
| `变异因子F` | 0.5 | - | 差分变异缩放因子。 | PAPER_EXPLICIT |
| `交叉概率CR` | 0.9 | - | 二项式交叉概率。 | PAPER_EXPLICIT |

## 复杂度

- 时间：`约为O(G·N·C_f)，C_f为一次完整遮蔽仿真的成本；为PAPER_DERIVED。`
- 空间：`约为O(N·D)，D为决策维度；为PAPER_DERIVED。`
- 说明：无

## 随机性与复现

- 使用随机性：否
- 必须固定 seed：否
- 说明：无

## 实现要点

- 采用惩罚函数处理投弹间隔等约束
- 问题四复算应使用与局部网格搜索相同的目标函数定义

## 常见失败模式

- 随机种群未覆盖优质区域
- 惩罚系数不当导致不可行解占优或可行域搜索困难
- 达到最大代数仍未收敛
