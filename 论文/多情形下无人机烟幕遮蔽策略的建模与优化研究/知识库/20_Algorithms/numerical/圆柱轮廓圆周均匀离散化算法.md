# 圆柱轮廓圆周均匀离散化算法

> [!abstract] 用途
> 以有限采样点近似圆柱上下底面圆周，从而执行完全遮蔽判定。

## 基本属性

- 分类：`numerical`
- 来源等级：`PAPER_EXPLICIT`
- 置信度：99%
- 输入：圆柱上下底面圆周、采样点数n、导弹位置和云团球体
- 输出：离散轮廓点集、近似完全遮蔽状态

## 伪代码

```text
1. 在上、下底面圆周分别均匀生成n个采样点
2. 对每个采样点构造导弹—目标点线段
3. 调用线段—球体相交判定
4. 若所有采样点均被遮挡，则近似判定圆柱完全遮蔽
5. 比较不同n的几何误差和遮蔽时长稳定性
```

## 初始化与停止条件

- 初始化：在[0,2π)上对圆周角进行等间隔采样。
- 停止条件：完成全部上下圆周采样点的判定；发现未被遮蔽点时可提前返回未完全遮蔽

## 参数

| 参数 | 值 | 范围 | 说明 | 来源 |
|---|---|---|---|---|
| `每个圆周采样点数n` | 300 | - | 论文在精度和效率之间折中采用的点数。 | PAPER_EXPLICIT |
| `n=300的面积相对误差` | 0.00731 | - | 正300边形相对圆面积的误差。 | PAPER_EXPLICIT |

## 复杂度

- 时间：`每个时刻O(n)，其中每个采样点进行常数次线段—球体相交计算；该复杂度为PAPER_DERIVED。`
- 空间：`显式保存点集时O(n)，流式判定时可为O(1)；论文未说明实现方式。`
- 说明：无

## 随机性与复现

- 使用随机性：否
- 必须固定 seed：否
- 说明：无

## 实现要点

- 上下两个底面圆周均需检查
- n≥300时论文报告遮蔽时长收敛到小数点后六位

## 常见失败模式

- 采样点过少导致漏检窄小未遮蔽区域
- 公式或坐标系错误导致所有采样点系统性偏移
