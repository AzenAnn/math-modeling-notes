# 仿真黑箱优化方法组合

## 什么是仿真黑箱优化

目标函数 $f(x)$ 没有便于求导的解析形式，只能给定决策变量 $x$，运行一次仿真得到函数值。常见特征：

- 目标由逻辑判定、时间积分或离散事件组成；
- 不连续、不光滑、非凸；
- 约束包含运动学、时序和可行性判定；
- 梯度不可得或数值梯度噪声很大。

本笔记抽象自 A196 论文 [p.14-p.33](../../paper.md#page-14)。

## 方法选择表

| 问题特征 | 建议方法 | 优点 | 主要风险 |
|---|---|---|---|
| 一维布尔可行区间 | 粗扫描 + 二分边界 | 快、精度可控 | 默认单区间可能漏解 |
| 2-6 维、仿真较便宜 | 多起点变步长坐标搜索 | 实现简单、收敛快 | 仍可能陷入局部最优 |
| 中等维度连续参数 | DE / PSO / CMA-ES | 不需梯度、全局搜索 | 仿真次数高，结果有随机性 |
| 有可用的机理规律 | 物理启发初值 + 局部搜索 | 大幅缩小搜索空间 | 机理近似偏差可能错过全局最优 |
| 离散分配 + 连续参数 | 整数规划 + 分解优化 | 可解释、便于处理容量约束 | 上层代理收益不准会影响全局结果 |
| 单次仿真非常昂贵 | 贝叶斯优化 / 代理辅助进化 | 节省仿真次数 | 建模与实现更复杂 |

## 1. 粗扫描 + 二分定位布尔区间

给定布尔状态函数 $B(t)\in\{0,1\}$，目标是求所有 $B(t)=1$ 的时间区间。

### 通用流程

```text
1. 在 [t0, t1] 上用较粗步长扫描 B(t)。
2. 记录所有 B(t_k) != B(t_{k+1}) 的小区间。
3. 对每个小区间分别二分，求状态切换时刻。
4. 将边界依次配对，得到全部可行区间。
5. 对区间取并集并计算总长度。
```

### 伪代码

```python
def find_true_intervals(predicate, t0, t1, coarse_step, tol):
    grid = make_grid(t0, t1, coarse_step)
    state = [predicate(t) for t in grid]
    boundaries = []

    for left, right, a, b in adjacent(grid, state):
        if a != b:
            boundaries.append(binary_transition(predicate, left, right, tol))

    return pair_and_merge(boundaries, predicate, t0, t1)
```

### 关键改进

A196 论文在问题一中论证可行集是一段连续区间，再分别定位左右边界。更通用的实现应先找出全部状态切换，避免对单连通性做错误假设。

## 2. 多起点变步长坐标搜索

适用于决策维度不高、变量范围明确、目标函数无梯度的问题。

### 核心思想

1. 在可行域中均匀随机生成 $N$ 个起点；
2. 从每个起点开始，沿坐标轴正负方向试探；
3. 发现改进就移动到新点；
4. 若一轮所有方向都无改进，缩小步长；
5. 比较所有起点的局部最优解。

### 归一化很重要

各变量的尺度可能差异很大。应先映射到 $[0,1]^d$，再使用统一的步长衰减规则，否则“角度的一步”和“时间的一步”没有可比性。

### 伪代码

```python
best = None
for x0 in sample_uniformly(bounds, n_starts):
    x = normalize(x0, bounds)
    step = initial_step

    while max(step) > tolerance:
        improved = False
        for j in range(dimension):
            for sign in (-1, 1):
                candidate = project(x + sign * step[j] * unit(j))
                if objective(candidate) > objective(x):
                    x = candidate
                    improved = True

        if not improved:
            step *= decay

    best = better(best, x)
```

## 3. 粒子群优化作为独立复核

PSO 并不一定比坐标搜索更好，但它的搜索机制不同，适合用来复核最优值是否稳定。

A196 中两种方法对四维问题的最优目标分别为 4.587300 s 和 4.587772 s，相对差异约 0.01%。比较时不能只看目标值，还应看：

- 决策变量是否具有相同物理特征；
- 不同随机种子的结果方差；
- 总仿真次数和运行时间；
- 约束违反情况。

## 4. 差分进化（DE/rand/1/bin）

适用于中等维度的连续黑箱优化。

### 变异

对目标个体 $x_i$，随机选择三个不同个体：

$$
v_i=x_{r_1}+F(x_{r_2}-x_{r_3}).
$$

### 二项式交叉

$$
u_{ij}=
\begin{cases}
v_{ij},&\operatorname{rand}_j\le CR
\text{ or }j=j_{\mathrm{rand}},\\
x_{ij},&\text{otherwise}.
\end{cases}
$$

### 贪心选择

最小化问题中：

$$
x_i^{(g+1)}=
\begin{cases}
u_i,&f(u_i)\le f(x_i),\\
x_i,&\text{otherwise}.
\end{cases}
$$

A196 的示例参数为种群规模 $N=100$、最大代数 $G=500$、$F=0.5$、$CR=0.9$。这些只是该问题的设置，不应当成通用默认值。

### 约束处理的优先级

1. **可行编码**：变量生成时就满足顺序和边界约束；
2. **修复算子**：交叉变异后把个体投影回可行域；
3. **Deb 可行性规则**：可行解优先，两个不可行解比较违反度；
4. **惩罚函数**：只在前三种不方便时使用，并报告惩罚系数敏感性。

## 5. 物理启发降维 + 局部精搜

当存在明确的机理规律时，可先构造近似最优解 $x_0$，再只在其邻域中搜索：

$$
x\in[x_0-\Delta,x_0+\Delta].
$$

例如动态拦截类问题中，可通过预测相遇点解出一组满足运动学约束的时间、方向和速度，然后对角度、速度和时间做局部网格或局部无梯度搜索。

这类方法的正确定位是：**高效的高质量近似解**，而不是自动获得全局最优的方法。

### 避免网格爆炸

若每个维度采样 $m$ 个点，$d$ 维完整网格需要 $m^d$ 次仿真。更实用的方案：

- 粗网格初选 + 坐标搜索；
- 拉丁超立方采样 + 局部搜索；
- 随机搜索 + 逐步缩小领域；
- 代理模型 + 期望改进采样。

## 6. 整数任务分配 + 连续子问题

高维混合问题应优先考虑分解。

上层任务分配：

$$
\max\sum_i\sum_j c_{ij}y_{ij}
$$

$$
\text{s.t.}
\quad
\sum_j y_{ij}\ge 1,
\quad
\sum_i r_{ij}y_{ij}\le R_j,
\quad
y_{ij}\in\{0,1\}.
$$

下层在给定 $y$ 后，对每个目标求连续参数最优解。

如果上层代理收益 $c_{ij}$ 较粗糙，可迭代更新：

```text
初始代理收益 -> 任务分配 -> 连续精优化
         ^                           |
         |-------- 收益回填 --------|
```

这与 Benders 分解、列生成和大邻域搜索的思想相近。

## 7. 必做的实验

### 随机稳定性

对 DE、PSO 等随机算法至少运行 20-30 次，报告：

- 最优值、中位数、均值、标准差和最差值；
- 可行解比例；
- 达到给定目标阈值的成功率；
- 仿真次数和运行时间。

### 离散误差

对空间采样点数 $n$、时间步长 $\Delta t$ 分别做收敛性测试。不要只检查几何近似误差，还要直接检查最终目标值的收敛。

### 独立算法复核

主算法是局部搜索时，用全局进化算法复核；主算法是进化算法时，用物理启发初值或小规模精确方法复核。

## 8. 常见错误

- 未做尺度归一化，导致大数值变量主导搜索。
- 把重叠时间段的长度直接相加，而没有先做区间并集。
- 惩罚系数过小导致不可行解获胜，过大导致可行域边界难以搜索。
- 只报告最好一次结果，不报告随机波动。
- 使用不同算法复核时，两者的仿真精度、约束和计算预算不一致。
- 看到一个资源的贡献为 0 就直接认为该资源无用，而没有排查收敛和约束处理问题。
