## 每篇目录约定

```text
编号-论文名/
├── README.md
├── 解读.md
├── source_map.json
├── translation_notes.md
├── assets/
├── workflow/
│   ├── parsed/
│   ├── ir/
│   └── reports/
├── 补充笔记/
│   ├── 模型/
│   └── 算法/
└── 知识库/
```

`workflow/parsed/normalized_paper.md` 是完整 OCR 正文；`workflow/ir/paper_ir.json` 是通过 Schema 的证据化结构；`知识库/` 包含 Paper、Case、Model、Algorithm 卡片。顶层 `解读.md` 面向直接阅读，正文事实应能回溯到页码或 Evidence ID。
